# LinkedIn Outreach Templates — Tyler Campbell
Use these for warm and cold outreach. Personalize every message. Goal: conversations and intros, not hard asks for jobs.

---

```
I’ve spent the last several years growing a $6–8M HVAC portfolio (20% YoY) and more recently building Harbourview — a market-intelligence platform with a 6,000+ global network.

If you hear of anything that fits, or know someone worth talking to, I’d really appreciate the intro. Happy to return the favour any time.

Best,
Tyler
```

## Cadence recommendation
- 5–10 thoughtful messages per week (quality over volume)
- Track in the Command Center under Contacts + Outreach
- Follow up once after 5–7 days if no reply
- Never mass-message identical copy
