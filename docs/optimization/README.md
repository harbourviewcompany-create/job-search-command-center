1. **Read** `IMPLEMENTATION_CHECKLIST.md`
2. **Paste** `BASE_RESUME.md` into Settings → base resume
3. **Load** `search_terms.json` into Settings
4. **Wire** `tailored_package_prompt.md` into Generate Package flow
5. **Activate** network outreach (5–10 messages this week)
6. **Sweep** Tier 1 target companies for open roles
